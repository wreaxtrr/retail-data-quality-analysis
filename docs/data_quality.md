# Data quality

Основные проблемы были выявлены на этапе profiling и обработаны в `02_data_cleaning.ipynb`.

| Проверка | Результат / решение |
|---|---|
| Исходный объём | 1 067 371 строк |
| Полные дубликаты | 12 133 строк удалены как вероятные повторы загрузки |
| Строк после удаления дубликатов | 1 055 238 |
| Пропуски `customer_id` | сохраняются для общей аналитики продаж, исключаются из customer analysis |
| Отрицательное количество | не считается обычной продажей |
| Отмены | определяются по префиксу `C` в invoice |
| Нулевая/отрицательная цена | исключается из обычных продаж |
| Служебные stock codes | исключаются из товарной выручки |
| Несколько описаний товара | используется наиболее частое описание |
| Товар без описания | остается в `products` с `NULL` |
| Несколько timestamp у invoice | берется минимальный timestamp |

Итоговая выборка обычных продаж:

- 1 025 074 строк;
- 39 555 счетов;
- 5 861 покупателей;
- 4 904 товара;
- 790 739 строк с известным `customer_id`.

Строки без `customer_id` не удалялись из основной очищенной таблицы, потому что они по-прежнему содержат информацию о продажах.
